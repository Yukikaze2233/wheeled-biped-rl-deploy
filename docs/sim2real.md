# sim2real 排查清单

按踩中概率排序。上真机前逐项打勾;出问题时从此表逆向定位。
核心经验:**大部分 sim2real bug 在合同层(观测/动作的索引、缩放、符号),
不在算法层。**

## A. 上真机前必须逐项核对

- [ ] **观测索引与缩放**:35D 逐维对照 CONTRACT.md §2,训练 cfg ↔ sim2sim ↔ 控制器三处一致
- [ ] **投影重力符号**:R^T @ [0,0,-1] 的约定一致(最常见 bug:实机前倾仿真后仰)
- [ ] **四元数顺序**:wxyz vs xyzw(若用四元数路径)
- [ ] **动作解码**:腿 = default + 0.5×a;轮 = clamp(10×a, ±30),限幅一致
- [ ] **PD 参数**:腿 Kp=60/Kd=2、轮速度环 0.2,训练与固件一致
- [ ] **default_dof_pos**:训练资产默认站姿 = 部署 PREPARE 目标位姿
- [ ] **延迟范围**:实机回环延迟落在训练随机化范围内(obs 20–80ms / act 20–60ms)
- [ ] **clamp 与 nan 防护**:obs ±100,nan/inf 置 0
- [ ] **ONNX 合同**:check_onnx_contract.py 通过

## B. real2sim 辨识(上真机前的最后一轮)

```text
1. 真机架空,驱动各关节跟踪预设轨迹(慢速正弦 + 快速阶跃),录 bag
2. MuJoCo(sim2sim)回放同一指令序列
3. 叠加对比关节位置/速度曲线
4. 调仿真端参数直至重合:
   - 跟踪滞后 → 关节摩擦/阻尼
   - 高速段力矩不足 → 电机曲线模型(用实测 CSV)
   - 整体延迟差 → delay ticks
5. 轮电机:直接辨识静摩擦 + 粘滞阻尼即可
6. 关节电机:单关节辨识意义不大(误差来自结构耦合),用整体拟合
```

## C. 出问题时的逆向定位

| 症状 | 首查 | 次查 |
|---|---|---|
| 实机抖动 | 延迟随机化是否覆盖实测延迟 | armature 是否漏算(转子惯量×减速比²) |
| 方向颠倒(前倾变后仰) | 投影重力符号 | 关节正方向约定 |
| 腿瞬间打满 | 动作 scale | 关节限位一致性 |
| PREPARE 后姿态偏 | default_dof_pos 训练/部署不一致 | 关节零位标定 |
| 缓慢漂移/静差 | delay 随机化 vs 实测(过大→定点静差) | 摩擦辨识 |
| 仿真走实机摔 | 逐帧对比 35D obs(debug topic) | 接触参数(摩擦/恢复系数) |
| OOD(训练没见过的行为) | 重启条件/指令分布覆盖 | 地形是否超出训练域 |

**逐帧对比法**:控制器 `rl_network_input/output` 调试 topic 与 sim2sim 的
obs/action 并排录,逐帧找第一个分叉的维度——分叉点就是 gap 所在环节。

## D. 部署阶段建议顺序

```text
1. PREPARE 插值观察(静态,零指令)      → 验证 PD/零位/方向
2. RL 策略架空悬空跑                     → 验证观测合理性(轮空转模式)
3. 系数降低的 RL(限速 0.3×)落地站立    → 验证平衡
4. 全速 RL 低速指令(±0.3 m/s)          → 验证跟踪
5. 逐步放开速度/模式
```

任何阶段异常,回上一阶段并转 C 表排查。
